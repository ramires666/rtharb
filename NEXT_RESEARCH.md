# Следующая очередь исследований

## 1. Сессионный VWAP

- Добавить отдельный RTH VWAP на графики QQQ и NVDA.
- VWAP каждого инструмента считать с 09:30 ET по сырым 1-минутным SIP-барам и обнулять в начале каждой сессии.
- Не использовать будущие значения. Первый допустимый сигнал — после как минимум трёх завершённых минутных баров; точный warm-up включить в сетку параметров.
- Проверить VWAP как основу fair-value / Z-score вместо текущей EMA-нормализации.
- Подбирать параметры только по схеме development → validation → один финальный holdout; отдельно показывать комиссии, slippage, turnover и устойчивость по периодам.

## 2. Искусственный индекс крупнейших tech-компонентов

- Это отдельная стратегия, не расширение NVDA-арбитража.
- Выбрать 3–4 крупнейших ликвидных технологических компонента Nasdaq-100, которые в сумме дают ориентировочно 30% веса индекса.
- Зафиксировать исторически корректный состав и веса для каждой даты, чтобы исключить survivorship bias и look-ahead.
- Нормализовать компоненты к единой базе на начало RTH-сессии и собрать взвешенный синтетический индекс; сырые цены акций напрямую не усреднять.
- Сравнить синтетический индекс с QQQ и отдельно проверить отклонение по Z-score и по абсолютному значению.
- Торговать QQQ/NQ на схождение с синтетическим индексом только внутри нью-йоркской RTH-сессии, с next-bar fills и теми же реалистичными издержками.
- Подбор и проверку также проводить через development → validation → holdout, включая чувствительность к составу, весам и задержке данных.
- Для финальной стратегии обязательно проверить bracket exits по тем же risk/reward-сеткам, что и для обычной стратегии.

## 3. Risk/reward для обычной стратегии

- Сначала провести same-entry cohort-тест на замороженных сигналах, чтобы не смешивать качество входа и выхода.
- Проверить reward/risk `0.5, 0.75, 1, 1.5, 2, 3` на сетке расстояний стопа от цены входа.
- В RR-ветке полностью игнорировать выход по схождению: закрывать только по stop, take-profit или принудительно в конце RTH-сессии.
- Если stop и target задеты внутри одного 1-минутного бара, использовать консервативное допущение stop-first.
- После устойчивого результата отдельно проверить динамическую версию, где ранний bracket-exit может разрешить новые входы.
- Одинаковую RR-методику применить отдельно к классическим frozen Z-входам и к выбранным walk-forward VWAP-Z-входам.

## Порядок

Сначала завершить VWAP-модель и её независимую проверку. Risk/reward обычной стратегии можно считать параллельно. Затем начинать исследование искусственного индекса.
