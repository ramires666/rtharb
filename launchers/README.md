# Однокнопочные запускатели

- `open_*.bat` — открыть готовый интерактивный отчёт;
- `rebuild_*.bat` — пересобрать отчёт из локального raw-кэша;
- `run_*.bat` — выполнить исследование, собрать отчёт и запустить аудит.

Все запускатели сами переходят в корень проекта и вызывают модули из
`rtharb/`, поэтому их можно запускать двойным щелчком из этой папки.
