# Frozen VWAP absolute — архив

Эта проверка повторно использовала заранее замороженный поток входов стратегии
на схождение. После раннего выхода по фиксированному stop/target новые сигналы
не регенерировались, поэтому результат нельзя считать самостоятельным bracket-
бэктестом.

Архив оставлен для сравнения с исправленным raw event-driven исследованием:
`tradingview_vwap_absolute/index.html`.

- `research.py` — старый расчёт;
- `audit.py` — проверка сохранённых старых артефактов;
- `run.bat` — архивный запуск;
- `output/results/` — исходные frozen-результаты и equity.
