# Ранние прототипы отчётов

Архив первых генераторов HTML/PNG/SVG и их артефактов. Эти файлы не участвуют
в текущем event-driven бэктесте, автоматических аудитах или интерактивных
TradingView-отчётах.

- `code/` — старые генераторы, экспортеры и экспериментальные серверы;
- `artifacts/` — созданные ими standalone/PNG/SVG материалы;
- `docs/` — старые августовские и стратегические отчёты;
- `launchers/` — устаревшие запускатели.

Архив сохранён только для истории. Рабочие точки входа описаны в корневом
`README.md`.
